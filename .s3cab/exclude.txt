# Exclude template for dogfooding s3cab on this repository.
# Excludes are now per-set (~/.s3cab/sets/<set>/exclude.txt), so this file is a
# ready-made template rather than a wired config: run `s3cab setup s3cab .` then
# copy these patterns into ~/.s3cab/sets/s3cab/exclude.txt.
# Syntax: see guide/exclude.md. '/' is always the separator, '**/' spans whole
# directories, '*' matches within a single segment, and a trailing '/' marks a
# directory. (The walker always skips a .s3cab/ directory, so it needs no rule here.)

# Dependencies and VCS metadata (matches the default a new set is born with)
**/node_modules/
**/.git/

# Operating-system noise (safe to skip on any platform)
**/.DS_Store
**/Thumbs.db
**/._*
**/desktop.ini
$RECYCLE.BIN/
System Volume Information/

# Build output and packaged binaries (esbuild bundle + SEA executable)
build/
dist/

# Test, coverage, and temporary output
coverage/
test/.tmp*/
**/*.tmp

# Logs
**/*.log
