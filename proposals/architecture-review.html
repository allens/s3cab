Verdict

Nearly the whole stretch is two subsystems: the snapshot-format revision (ADR-0098–0107: five columns, -/@/# marks, validity, the lone ., @S3CAB SPEC/@CLIENT) and set ownership (ADR-0108: snapshots/<set>.info, a read-only reattach, takeover). Beside them: the bucket and identity stacks (ADR-0105), **/ mid-name and macOS folding (#399), names with no UTF-8 form (#398), the resized progress line (#410).

This pass's main shape: the format revision landed its writer in one module and its reader in two. The deletion record composes the snapshot writer's HEADING, openingRows, formatLine and TERMINATOR, then re-states the reading rules in a parser of its own, which already disagrees with the snapshot's on three of them. The same shape in miniature: the walk refuses a name the snapshot can't hold by two mechanisms that disagree on directories, and takeover asks "is this machine the holder" twice. A second shape: a rule the registry already states, which two commands re-check by hand while every other command ignores it.

Problem.
What makes an s3cab file valid is implemented twice, and the two readers already disagree: a whitespace-only line, a file ending .\n., and a file that isn't UTF-8 (the record arrives through getText's lenient decode, so ADR-0101's refusal can't reach it).
Solution.
One line-walker in snapshot-file.mjs owns the file-level rules over bytes and takes a per-type row handler; parseDeletionRecord keeps only what a #deleted row is and its own "a malformed row distrusts the record" verdict. Knowledge moves into the grammar's owner, so ADR-0028 stands.
  • locality: validity changes once
  • interface: record parser loses six rules
  • tests: one damage table, two readers
  • UTF-8 refusal reaches the record
  • five hand-spelled test framings go

Top recommendation

One reader for a valid s3cab file

Both parsers are a week old and already disagree on three of the rules ADR-0101 wrote down, one of them the safety-relevant UTF-8 refusal that can't reach the deletion record at all. The fix moves knowledge into the module ADR-0028 already names as the grammar's owner, and it is the only candidate that turns two hand-mirrored damage tables into one test asserted through both seams.
